    FAQ
    
  
    
    
    
      What is an AI agent spending policy?
      
    A spending policy is a set of rules that decide, for every payment an AI agent tries to make, whether it is allowed automatically, sent to a human for approval, or blocked. Rules are checked in order and the first one that matches a payment decides the outcome.
    
    
    
    
    
      How does this generator turn my answers into rules?
      
    Each answer maps to one field in a Pink rule: what the agent buys becomes a payee category, your auto-approve limit becomes an allow rule's maximum, your approver choice becomes that rule's approvers, and an optional daily hard stop becomes a block rule with no approval path. The generator never invents a rule shape the sandbox does not support.
    
    
    
    
    
      Does Try it live move real money?
      
    No. Try it live creates a free sandbox workspace with test money and test payees, loads your generated rules into it, and fires a few policy checks so you can see the allow, ask and block decisions. No real payment ever executes.
    
    
    
    
    
      Can I use the generated rules outside the sandbox?
      
    The rules JSON is the format the Pink sandbox API accepts today, and the copyable curl script shows exactly which endpoints load it. Production access is by early access; if you want to carry a sandbox policy over, request early access on pinkwallet.com/agentic.
    
    
    
    
    
      What happens to a payment that does not match any rule?
      
    The default is block. The policy engine checks rules top to bottom and stops at the first match; if nothing matches, the payment is blocked, not allowed by default.
